Google Search Console (do this after HTTPS is on)

  1. Open Google Search Console and add https://safetytestprep.com
  2. Verify the domain (DNS TXT at GoDaddy is cleanest)
  3. Sitemaps → submit https://safetytestprep.com/sitemap.xml
  4. URL inspection → Request indexing for /, /osha/, and each quiz page you posted

Until GitHub shows a certificate and Enforce HTTPS is on, skip this step — Google wants the https version.
