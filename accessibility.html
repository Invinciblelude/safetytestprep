Accessibility

Accessibility

We aim to keep the site readable on a phone, with clear headings, visible buttons, and quizzes you can operate from the keyboard. We have not completed a formal WCAG audit.

Known limits

Practice labs use a dark theme and custom quiz controls. Some older browsers or assistive tools may not announce every state change. Color is not the only cue for correct/incorrect answers, but contrast has not been certified.

Request help

If a page or quiz is hard to use, email safetytestprep@gmail.com with the page URL and what you need (for example larger text, a text-only version of a question, or a keyboard issue). We will work on a practical fix.
